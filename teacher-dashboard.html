Students

Add students to a class. A one-time access code is generated and stored as a SHA-256 hash. Copy the code when it appears; it will not be shown again. Student sign-in and testing are not implemented yet.

Choose a class to load students.

Privacy and safety: only add student information you are authorized to manage. This page does not provide student login, assessment assignment, result tracking, or PIN verification. Access codes are stored as hashes, but a secure server-side student authentication workflow must be built before students use them.
