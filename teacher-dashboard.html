Students

Add students to a class. A one-time access code is generated and stored as a SHA-256 hash. Copy the code when it appears; it will not be shown again. Students can use the Student Portal to sign in and take supported published multiple-choice assessments assigned to their active class.

Bulk add students

Choose the class above, then paste one student per line. Format: Nickname, Student number or Nickname[TAB]Student number. Existing student numbers and duplicates in the pasted list are skipped.

Choose a class to load students.

Privacy and safety: only add student information you are authorized to manage. Student sign-in and supported multiple-choice delivery are available through the Student Portal when the Edge Function is deployed and configured. PIN verification, strict exam controls, and student-facing result history are not implemented yet. Do not use this first release for high-stakes exams.
